# Belajar Backend

Kumpulan project latihan backend, ditulis sebagai bagian dari proses belajar Node.js dan Express.js.

## Daftar Project

| Folder               | Deskripsi                                                               | Status                               |
| -------------------- | ----------------------------------------------------------------------- | ------------------------------------ |
| 01-Game              | REST API daftar game                                                    | Dibantu AI, belum sepenuhnya mandiri |
| 02-Daftar_Kedai_Kopi | REST API kedai kopi — routing, middleware, validasi ID, filter rating   | Ditulis mandiri                      |
| 03-Daftar_Film       | REST API film — filter multi-query (genre & tahun), middleware validasi | Ditulis mandiri                      |
| 04-Toko_Sepatu       | REST API toko sepatu — 3 middleware berlapis, simulasi alur pembelian   | Ditulis mandiri                      |

## Tech Stack

Node.js, Express.js

## Catatan

Setiap folder project memiliki README sendiri dengan detail fitur dan cara menjalankan.
